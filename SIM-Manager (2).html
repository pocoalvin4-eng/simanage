📤 Di HP / Browser Lama

  1. Buka tab Backup & Restore
  2. Klik tombol Export JSON
  3. File simcards.json akan terunduh otomatis
  4. Kirim file ke Google Drive, WhatsApp, atau email ke diri sendiri

📥 Di HP / Browser Baru

  1. Salin file SIM-Manager.html ke HP baru
  2. Buka file di browser (Chrome / Firefox)
  3. Buka tab Backup & Restore
  4. Klik Import → pilih file simcards.json tadi
